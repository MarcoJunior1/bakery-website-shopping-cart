# Maravilhas do Trigo — Site de Padaria

Site de uma **padaria** ("Maravilhas do Trigo") com cardápio, produtos e carrinho de compras.

## ✨ Seções

- Início, **Sobre nós** e **Cardápio**
- **Produtos** com botão "adicionar no carrinho" e lista do carrinho (com "Limpar Lista")
- **Kits Festa**
- **Nossa Padaria**, redes sociais e **avaliações** de clientes

## 🗂️ Estrutura

```
├── index.html
├── css/style.css
└── images/Img_Pinterest/   # imagens do cardápio, blog e produtos
```

## 🛠️ Tecnologias

HTML · CSS · JavaScript

## 🚀 Como usar

Abra `index.html` no navegador.

> Alguns textos e preços ainda são *placeholders* ("Nome do Produto", "xxxx") e precisam ser preenchidos.
